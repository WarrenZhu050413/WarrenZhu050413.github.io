# Seated proportion study

Superseded by `groom/`, which builds the poem's long-haired cat. Kept for reference.

This is a separate, unrigged sculpture made after the walking cat was rejected.
It focuses on the supplied reference's broader head, seated chest silhouette,
close front paws, resting tail, and layered coat. It is not a replacement asset
for the poem or an approved match to the reference.

Run `Blender --background --python prototypes/opus-memory/blender/portrait/study.py`.
It writes `portrait.blend` and `portrait.png` here. The comparison page is
`/prototypes/opus-memory/blender/portrait/` on the local Jekyll preview.

The fur consists of tapered Blender curves. It renders in Cycles, but no browser
export or performance claim has been made for this sculpture. Preserve this
distinction when testing the eventual rig and glTF representation. `reference.png`
is the user-supplied approved illustration used for this comparison.
